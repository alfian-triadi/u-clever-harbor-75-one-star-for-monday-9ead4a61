A one-line program that writes a one-star review of Monday as if it were a restaurant: seated at 7 a.m., coffee forgotten, and billed for the entire week ahead — short enough to screenshot into the group chat.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
